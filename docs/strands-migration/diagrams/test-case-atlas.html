Simulation Substrate — deterministic mocks the loop tests run against

Six fakes (FakeLLM · FakeRenderer · FakeTTS · FakeB2 · FakeClock · FakeInterrupt) plus a composer Substrate and an OrchestratorSimulator that boots a real create_deep_agent() on top of the fakes. Every cyclic graph test exercises this substrate before running live.

FakeLLM

Scripted rules, reusable deep-copy, locked dispatch.

FakeRenderer

Worker pool; health snapshots under lock.

FakeTTS

Per-voice synth; transient/persistent fault injection.

FakeB2

Content-addressed cache; verify_bytes on store.

FakeClock

Monotonic, advanceable, deterministic jitter.

FakeInterrupt

Scripted approval decisions, deep-copied.

Trajectory Tests — what the agent did, not just what it returned

Each trajectory test drives a component through the sim substrate and asserts the exact sequence of tool calls, the per-iteration shape of the loop, and the presence of contractual side-effects.

Media Corpus & Judge Fleet — real artifacts, real judges

Content-addressed B2 cache of media fixtures (audio WAV/LUFS-spec, PNG stills, short MP4 clips, OTIO timelines). A blinded pair-discrimination harness shows every judge a yes artifact and a no artifact on the same axis and demands both verdicts right.

Judge Fleet

Gemini 3.1 Pro (text + vision + audio · remote)
Qwen3.5-Omni (video + audio · remote)
Gemma 4 abliterated (local, B2-hosted)

Judge Ensemble

Local-first routing; proprietary fallback; JSON-blob verification; disabled-judge detection via gemini_disabled / qwen_disabled fields.

Pair Discrimination

16 axes × (yes, no) = 32 artifacts per nightly run.
Verdicts: both_correct / yes_only / no_only / both_wrong / unclear.

Tier-2 Nightly

CI matrix (linux · macos · py3.11/3.12) · shell-injection-safe workflow · exit-code-2 = neutral · artifacts uploaded on failure.
