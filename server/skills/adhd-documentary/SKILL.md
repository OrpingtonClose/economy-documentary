# ADHD-Friendly Documentary Format

## 3-Voice Structure

Every scene MUST use all 3 voices:

### V1 — The Hook
- Opens each scene with a provocative, attention-grabbing statement
- Challenges assumptions, presents counterintuitive claims
- Tone: bold, direct, slightly confrontational
- Example: "Everything you know about inflation is wrong."

### V2 — The Expert
- Provides data, evidence, nuance after the hook
- Backs up claims with specifics — numbers, dates, sources
- Tone: calm, authoritative, measured
- Example: "Between 2020 and 2023, the M2 money supply expanded by 40%."

### V3 — The Storyteller
- Adds the human angle, emotional connection
- Relates abstract concepts to lived experience
- Tone: warm, empathetic, conversational
- Example: "Maria watched her grocery bill double while her paycheck stayed the same."

## Dopamine Hooks

Every scene MUST open with an attention-grabber in the first 3 seconds:
- Surprising fact or statistic
- Counterintuitive claim
- Vivid sensory image
- Direct challenge to the viewer

## Narrative Arc

Scenes should build across the documentary:
1. **Hook** — Grab attention with the most surprising angle
2. **Context** — Set the stage, establish what most people believe
3. **Tension** — Reveal the conflict, the hidden truth
4. **Evidence** — Present the data that supports the new perspective
5. **Insight** — The "aha" moment — connect the dots
6. **Resolution** — What this means for the viewer, forward-looking

## Rules

1. NO rhetorical questions — make declarative statements instead
2. Each scene <= maximum duration when spoken at natural pace
3. Each scene MUST specify different visual approaches for variety
4. Build narrative arc across scenes: hook → tension → insight → resolution
5. V1/V2/V3 should sound genuinely different in tone and pacing
