# 📚 Glossary

A consolidated technical glossary defining the architectural terms, systems, and protocols utilized within the documentary production pipeline.

---

## 📖 Architectural Term Definitions

| Term | Domain | Definition |
| :--- | :--- | :--- |
| **Assembly Agent** | Agent Role | The coordinator agent responsible for compiling individual audio and video clips into a single coherent OpenTimelineIO sequence and outputting the final movie file. |
| **Block** | Pipeline Core | A unit of production work corresponding to a specific role (e.g., `scenario`, `audio`, `video`, `assembly`). Each block carries its own schema, target VM configuration, and retry budget. |
| **BudgetLedger** | Cost Control | An active accumulator tracking LLM tokens, GPU leasing, and network egress bandwidth against a per-run cost ceiling (default $10.00). |
| **Coordinator** | Infrastructure | The collection of agent microservices and the SQLite event store running locally on the control plane host. |
| **Deep Agent** | Agent Core | An autonomous agent built using `pydantic-deep`, incorporating history hooks, prompt-based loop detection, and context compaction. |
| **Dual-Threshold Validation** | Assembly | Acceptance criteria requiring generated clips to meet both a relative deviation limit (15%) and an absolute duration offset (0.25 seconds) to pass quality gates. |
| **Effect** | Event Sourcing | A typed Pydantic model representing a single state change or mutation. Effects are the only legal way to mutate pipeline state. |
| **Emergent Phase** | Pipeline State | Descriptors (SCRIPT, AUDIO_RECONCILE, VIDEO_PRODUCTION, ASSEMBLY, DONE) representing the current pipeline state as derived from event folds, without using a hardcoded state machine. |
| **Event** | Event Sourcing | An immutable, append-only record of an applied effect in the SQLite log (`events.db`), carrying a monotonic sequence number and epoch timestamp. |
| **Event Loop** | Agent Core | The execution sequence of a pipeline agent: wake up via POST /, build prompt context from memory, query GSA projections, invoke LLM, run command tools, and write output text. |
| **Event Store** | Event Sourcing | The persistent SQLite database database file (`events.db`) containing the append-only event log. |
| **Generation Plan** | Timeline | The structured JSON schema generated by the Scenario Agent containing scenes, shot plans, and speaker roles. |
| **GSA** | Orchestration | **Global State Agent.** The primary state server (Port 8000) that reads `events.db` and exposes in-memory folded projections via REST. |
| **LoopBoundLock** | Concurrency | An asynchronous lock mechanism used to serialize agent reasoning turns within each microservice process, preventing database write conflicts. |
| **LTX-Video** | Media Engine | The diffusion-based local video rendering model (LTX-2.3) deployed on GPU worker VMs, requiring a minimum of 48 GB VRAM. |
| **OTIO** | Timeline | **OpenTimelineIO.** The open-source API and exchange format used to represent, validate, and manipulate the visual and audio tracks of the documentary screenplay. |
| **Projection** | Event Sourcing | A read-optimized, in-memory Python data model constructed by folding over the database event log. Rebuilt incrementally on every request. |
| **Prompt-Based Rules** | Agent Core | Invariant rules and fallback decisions embedded in system prompts rather than hardcoded in application logic. |
| **Run** | Pipeline Core | A single execution of the pipeline producing one completed documentary movie. |
| **SD-JSON** | Timeline | **Screenplay Data - JSON.** The normalized structure representing parsed screenplays, including scene numbers, narration lines, and visual cues. |
| **Situation** | Agent Core | A structured prompt condition representing a specific pipeline state (e.g. `fresh_dirty_block`) that prompts an agent action. |
| **TTS** | Media Engine | **Text-To-Speech.** The speech synthesis model (Qwen3-TTS) deployed on worker VMs to convert dialogue text into WAV clips. |
| **Vast.ai** | Infrastructure | The decentralized cloud GPU leasing platform used to provision ephemeral workers for speech and video rendering. |
| **VM Worker** | Infrastructure | An ephemeral GPU virtual machine provisioned by the Provisioner Agent to execute resource-intensive media jobs. |
| **WhisperX** | Media Engine | A forced-alignment tool running on worker VMs to generate word-level audio timestamps for precise word-to-video alignment. |
